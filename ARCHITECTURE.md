# Canonical danmaku boundaries

The plugin caches `DanmakuDocument` objects, never source text or IPC-encoded strings. Local files, network comment responses and old DDP disk caches enter through `parseDanmakuSource()` in `danmaku-document.js`. Document source fields and command arrays are immutable; `simplifiedText` is the only writable memo. Native dates, premium status and owner commands are retained for engine compatibility. XML format detection reads the root after the prolog, excluding PI/comment/DOCTYPE text from both sniffing and comment extraction. Nico XML premium is true only for the literal attribute `premium="1"`; Bilibili/DDP retain RGB command support.

`projectDanmaku()` applies date selection, density quotas, memoized conversion and blocking, then builds shared static dedupe groups. Owners/easy/undated comments survive date slicing; owners/easy and comments with at least three nicoru do not consume density quotas. A window with incomplete ordering signals uses evenly spaced sampling. The cached projection supplies screen comments, sidebar rows and statistics. Forced simplification applies only to Bilibili XML and Dandanplay documents. Niconico V1/legacy JSON and XML retain their original text in both screen and list projections, even with a saved enabled preference or an existing converted memo. Main does not construct a converter for Nico; the sidebar hides the complete switch row for Nico sources and retains the saved setting for later Chinese sources. Owner control text beginning with `/`, `@` or `＠` is never converted. Equivalent formatted projections skip renderer reloads; renderer failures and source changes invalidate that comparison. Dedupe uses an inclusive window from the earliest member and groups by text, position and blocked state; owners are excluded. The sidebar list applies that static policy to every position; the screen feed applies it to scrolling comments only. Fixed (ue/shita) comments reach the overlay unmerged, and the engine's `fixedCombo` (enabled with the dedupe switch) chains on-screen duplicates progressively (x2 → x3). Native CA duplicate removal is disabled for projected data. Overlay uses `keepCA: true, dedupeCA: false`: classification and `updateLayerId()` still run, while `removeDuplicateCommentArt()` does not. The engine keeps its old default for other consumers.

`postSafeMessage()` alone serializes data for WebViews. Payloads containing template syntax, curly quotes or lone surrogate code units use a URI-encoded JSON envelope; ordinary quotes, newlines and backslashes stay on the plain-object path. Lone surrogates are escaped as JSON Unicode escapes before URI encoding; both WebViews decode it in `onPluginMessage()`. Paths and text remain literal in business code. Overlay accepts formatted arrays and performs no source parsing. List chunks use the same envelope.

`pluginState` owns settings and session metadata. `commitState()` writes changed preferences through the existing debounce and sends incremental notifications. Sidebar requests one initial snapshot after registering handlers, then sends user intents. Retired state events are removed, related patches are batched, and native observer installation sends no playback replay. A custom-font field owns its draft/caret during composition and while its submitted family awaits acknowledgment. `compositionend` submits a final composing-only edit; an empty Custom choice survives focus moving to the weight slider. Speed and weight inputs keep view-only pointer-drag flags, so a released but still-focused range accepts preset echoes. Speed and weight apply live on every input; only the matching change in that same edit is suppressed, so selecting a preset never prevents a later edit from restoring a previously sent value. Gesture cleanup never overwrites the dragged value. Density re-projects every comment, so input captures a view-only draft and applies it after a 150 ms pause; release flushes the captured final value immediately. Pending density drafts retain their value and label through state echoes, keyboard editing and interrupted drags. A trailing change after the timer sent the draft does not re-read an echoed DOM value, and a later edit is never deduplicated against historical submissions. Hiding the sidebar, changing tabs or sources, window blur and pointer cancellation end input/change pairing while retaining any pending density setting. Idle network status releases the previous loading bangumi row. Invalid or unchanged date selections produce no projection/list refresh; opacity is constrained to 0–1, offset messages require finite numbers, and all manual DDP selections use the same ID type validation. An element blur during a WebKit drag is not a release; pointer release/cancel, capture loss and window blur end protection. Blocklist rendering is deferred while its inline editor is active, including external enable/word-list changes. `/.../` entries are compiled once per list change in `commitState()`; entries that fail to compile, exceed the length cap or let a group repeat (maximum above 1, bounded or not) over a body containing a quantifier or alternation (e.g. `(a+)+`, `(a+){9}`, `(a|aa)+`), or that combine multiple variable choices on one alternative (optional or bounded repetitions and alternatives inside groups, e.g. `a?a?...b`, `a{0,16}a{0,16}...b`, `.*.*x`; a backreference to a variable-length capture also counts, e.g. `(.*)\1x`), fall back to literal matching and are reported to the sidebar as `blocklist.invalid`. Variable wildcard repetitions require a preceding `^` on each alternative; combining multiline and dot-all flags with such wildcards is conservatively rejected. Named captures and references are read to their closing `>` within the complete bounded pattern and normalized with Unicode escape decoding. Unicode literal escapes in `/u` patterns are consumed as atoms rather than mistaken for quantifiers. Matching regressions use deterministic result assertions instead of a 200 ms wall-clock deadline. Explicit file-dialog selections force a disk refresh; list selections reuse the session document, and a failed refresh preserves the active source. Reselecting the current document retains its date slice and pending/successful load state; only changed projections are resent, and a disabled unchanged renderer resumes with one playback snapshot. Font family/weight intents carry only the edited field; main merges them before forwarding, so delayed sidebar echoes cannot overwrite the other field. Documents, cached projections and native callback handles are runtime resources outside the settings snapshot.

Style preset values live only in main. Sidebar sends one named intent, and main commits all preset parameters together and sends one complete appearance tuple to overlay. The old renderer keeps its original scale, font, stroke and speed until one replacement is built. A speed update arriving during a pending style rebuild is consumed by that replacement, never applied to the old renderer. This prevents a large-font/old-slow-speed frame when moving from Balanced to Nico.

OpenCC is loaded with package-local `require` while the main entry script is executing. IINA's native resolver depends on that script stack, so asynchronous callbacks only construct/use the converter. The bundle loads once and converter construction remains lazy; no WebView path reports or eval are used.

The overlay clock stores pure video time. Offset is applied only at drawing. Enabling and loading carry `{enabled, time, paused, speed}` atomically; pause/speed changes reanchor pure video time. Seek detection compares actual movement with elapsed wall time at the current playback rate, with a smaller drift threshold for forward nudges. Completed native `mpv.seeking` events explicitly synchronize even sub-threshold seeks. Only `overlay-ready` completes initialization. A pending load slot always points to the latest selected source/settings. `isLoaded` and the success OSD wait for the current render acknowledgment; success does not resend the file list. Failure clears the active selection/overlay while retaining the file and error row for explicit retry. Navigation invalidates old acknowledgments immediately.

The forked engine owns `scrollSpeed`, including CSS transitions, Canvas displacement, derived visibility ranges and collision sampling. `setScrollSpeed()` retains parsed comment instances, native `long`/`@N`, measured glyphs and existing CSS nodes. Owner motion remains native. Multiple runtime updates coalesce into one timeline/lane recalculation at the next draw; positions reflect the new motion model. CSS nodes restart once using alternating equivalent animation names, with no per-node forced layout reads. The sidebar sends speed live while dragging; the engine coalesces updates to the next draw, and visible paused playback performs one immediate draw per update. This is not constant-time, and no order-of-magnitude performance claim is made. The plugin does not inject duration commands or rebuild the renderer when only speed changes. While disabled, it retains settings and current projection inputs without sending source reloads, constructing renderers or drawing into hidden DOM. Style rebuilds remain pending; enabling compares the latest projection and either loads it once or resumes/rebuilds the existing source once.

DDP writes are serialized and failures do not poison the queue. A versioned cache stores canonical comments; old cache rows are normalized on read. Independent request generations reject obsolete matching, searches and bangumi responses.

## Engine provenance and validation

The bundled `overlay/lib/niconicomments.min.js` is generated from the sibling `niconicomments-dom` repository, commit `82fc905`, on `develop`. Use the fork's existing `rolldown -c rolldown.config.mjs` build and copy `dist/bundle.js`; do not hand-edit the vendored file.

- Plugin: `node --test test/*.test.js` and syntax checks for all entry/module files.
- Engine: TypeScript check, JavaScript/declaration builds, `vitest run`, and `playwright test -c playwright.motion.config.ts` (WebKit).
- WebKit CA tests verify that disabling duplicate removal keeps viewer/owner IDs and CA layers in CSS and Canvas. The actual plugin overlay also matches the four source/list records for Nico XML, V1 and legacy JSON. A delayed-echo font test preserves weight 800 while changing family.
- The WebKit motion test verifies DOM/instance reuse, one restart per scrolling node, zero `offsetWidth` reads during speed changes, preserved owner motion, paused state, bottom alignment, colored suffixes and the shared horizontal motion formula.
- WebKit mouse-drag checks verify speed/weight previews, preset values/labels updating even with retained range focus. Unit coverage includes release outside the control, cancellation, capture loss, window blur and input blur during an ongoing drag.
- A WebKit frame-sampling check exercises the actual sidebar intent → main transaction → overlay message, including delayed delivery. On a fixed test corpus it observes only complete Balanced and Nico states (42 → 21 DOM comments), one appearance message and one renderer replacement.
- An additional local WebKit smoke run loaded the plugin's actual overlay and sidebar HTML, exercised mixed Flash/HTML5 comments and literal template characters, and confirmed snapshot/settings traffic, font spaces/caret preservation Canvas activation from a disabled state, composing-only IME commit sequences, empty Custom mode, inline blocklist drafts and deferred hidden rendering without page errors.

The plugin still has no build step or runtime package manager. Release packaging includes `danmaku-document.js`, `ipc-transport.js`, `plugin-i18n.js`, `episode-matcher.js`, and `ddp-client.js`, and omits the retired `overlay/input.js`.
