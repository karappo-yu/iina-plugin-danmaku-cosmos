# Canonical danmaku boundaries

The plugin caches `DanmakuDocument` objects, never source text or IPC-encoded strings. Local files, network comment responses and old DDP disk caches enter through `parseDanmakuSource()` in `danmaku-document.js`. Document source fields and command arrays are immutable; `simplifiedText` is the only writable memo. Native dates, premium status and owner commands are retained for engine compatibility.

`projectDanmaku()` applies date selection, density quotas, memoized conversion and blocking, then builds shared static dedupe groups. Owners/easy/undated comments survive date slicing; owners/easy and comments with at least three nicoru do not consume density quotas. A window with incomplete ordering signals uses evenly spaced sampling. The cached projection supplies screen comments, sidebar rows and statistics. Owner control text beginning with `/`, `@` or `＠` is never converted. Equivalent formatted projections skip renderer reloads; renderer failures and source changes invalidate that comparison. Dedupe uses an inclusive window from the earliest member and groups by text, position and blocked state; owners are excluded. Both scrolling and fixed comments use that static policy. Native fixed progressive combo is disabled for projected data.

`postSafeMessage()` alone serializes data for WebViews. Payloads containing template syntax, curly quotes or lone surrogate code units use a URI-encoded JSON envelope; ordinary quotes, newlines and backslashes stay on the plain-object path. Lone surrogates are escaped as JSON Unicode escapes before URI encoding; both WebViews decode it in `onPluginMessage()`. Paths and text remain literal in business code. Overlay accepts formatted arrays and performs no source parsing. List chunks use the same envelope.

`pluginState` owns settings and session metadata. `commitState()` writes changed preferences through the existing debounce and sends incremental notifications. Sidebar requests one initial snapshot after registering handlers, then sends user intents. Retired state events are removed, related patches are batched, and native observer installation sends no playback replay. A custom-font field owns its draft/caret during composition and while its submitted family awaits acknowledgment. `compositionend` submits a final composing-only edit; an empty Custom choice survives focus moving to the weight slider. Blocklist rendering is deferred while its inline editor is active, including external enable/word-list changes. Explicit file-dialog selections force a disk refresh; list selections reuse the session document, and a failed refresh preserves the active source. Documents, cached projections and native callback handles are runtime resources outside the settings snapshot.

OpenCC is loaded with package-local `require` while the main entry script is executing. IINA's native resolver depends on that script stack, so asynchronous callbacks only construct/use the converter. The bundle loads once and converter construction remains lazy; no WebView path reports or eval are used.

The overlay clock stores pure video time. Offset is applied only at drawing. Enabling and loading carry `{enabled, time, paused, speed}` atomically; pause/speed changes reanchor pure video time. Seek detection compares actual movement with elapsed wall time at the current playback rate, with a smaller drift threshold for forward nudges. Completed native `mpv.seeking` events explicitly synchronize even sub-threshold seeks. Only `overlay-ready` completes initialization. A pending load slot always points to the latest selected source/settings. `isLoaded` and the success OSD wait for the current render acknowledgment; success does not resend the file list. Failure clears the active selection/overlay while retaining the file and error row for explicit retry. Navigation invalidates old acknowledgments immediately.

The forked engine owns `scrollSpeed`, including CSS transitions, Canvas displacement, derived visibility ranges and collision sampling. `setScrollSpeed()` retains parsed comment instances, native `long`/`@N`, measured glyphs and existing CSS nodes. Owner motion remains native. Multiple runtime updates coalesce into one timeline/lane recalculation at the next draw; positions reflect the new motion model. CSS nodes restart once using alternating equivalent animation names, with no per-node forced layout reads. The sidebar previews speed while dragging and commits on release; visible paused playback performs one immediate draw. This is not constant-time, and no order-of-magnitude performance claim is made. The plugin does not inject duration commands or rebuild the renderer when only speed changes. While disabled, it retains settings and current projection inputs without sending source reloads, constructing renderers or drawing into hidden DOM. Style rebuilds remain pending; enabling compares the latest projection and either loads it once or resumes/rebuilds the existing source once.

DDP writes are serialized and failures do not poison the queue. A versioned cache stores canonical comments; old cache rows are normalized on read. Independent request generations reject obsolete matching, searches and bangumi responses.

## Engine provenance and validation

The bundled `overlay/lib/niconicomments.min.js` is generated from the sibling `niconicomments-dom` repository, commit `c5cfa20`, on `codex/canonical-danmaku-ir`. Use the fork's existing `rolldown -c rolldown.config.mjs` build and copy `dist/bundle.js`; do not hand-edit the vendored file.

- Plugin: `node --test test/*.test.js` and syntax checks for all entry/module files.
- Engine: TypeScript check, `vitest run`, and `playwright test -c playwright.motion.config.ts` (WebKit).
- The WebKit motion test verifies DOM/instance reuse, one restart per scrolling node, zero `offsetWidth` reads during speed changes, preserved owner motion, paused state, bottom alignment, colored suffixes and the shared horizontal motion formula.
- An additional local WebKit smoke run loaded the plugin's actual overlay and sidebar HTML, exercised mixed Flash/HTML5 comments and literal template characters, and confirmed snapshot/settings traffic, font spaces/caret preservation Canvas activation from a disabled state, composing-only IME commit sequences, empty Custom mode, inline blocklist drafts and deferred hidden rendering without page errors.

The plugin still has no build step or runtime package manager. Release packaging includes `danmaku-document.js` and omits the retired `overlay/input.js`.
