# Canonical danmaku boundaries

The plugin caches `DanmakuDocument` objects, never source text or IPC-encoded strings. Local files, network comment responses and old DDP disk caches enter through `parseDanmakuSource()` in `danmaku-document.js`. Document source fields and command arrays are immutable; `simplifiedText` is the only writable memo. Native dates, premium status and owner commands are retained for engine compatibility. XML format detection reads the root after the prolog, excluding PI/comment/DOCTYPE text from both sniffing and comment extraction. Nico XML premium is true only for the literal attribute `premium="1"`; Bilibili/DDP retain RGB command support.

`projectDanmaku()` applies date selection, density quotas, memoized conversion and blocking, then builds shared static dedupe groups. Owners/easy/undated comments survive date slicing; owners/easy and comments with at least three nicoru do not consume density quotas. A window with incomplete ordering signals uses evenly spaced sampling. The cached projection supplies screen comments, sidebar rows and statistics. Owner control text beginning with `/`, `@` or `＠` is never converted. Equivalent formatted projections skip renderer reloads; renderer failures and source changes invalidate that comparison. Dedupe uses an inclusive window from the earliest member and groups by text, position and blocked state; owners are excluded. Both scrolling and fixed comments use that static policy. Native fixed progressive combo and CA duplicate removal are disabled for projected data. Overlay uses `keepCA: true, dedupeCA: false`: classification and `updateLayerId()` still run, while `removeDuplicateCommentArt()` does not. The engine keeps its old default for other consumers.

`postSafeMessage()` alone serializes data for WebViews. Payloads containing template syntax, curly quotes or lone surrogate code units use a URI-encoded JSON envelope; ordinary quotes, newlines and backslashes stay on the plain-object path. Lone surrogates are escaped as JSON Unicode escapes before URI encoding; both WebViews decode it in `onPluginMessage()`. Paths and text remain literal in business code. Overlay accepts formatted arrays and performs no source parsing. List chunks use the same envelope.

`pluginState` owns settings and session metadata. `commitState()` writes changed preferences through the existing debounce and sends incremental notifications. Sidebar requests one initial snapshot after registering handlers, then sends user intents. Retired state events are removed, related patches are batched, and native observer installation sends no playback replay. A custom-font field owns its draft/caret during composition and while its submitted family awaits acknowledgment. `compositionend` submits a final composing-only edit; an empty Custom choice survives focus moving to the weight slider. Speed and weight inputs keep view-only pointer-drag flags, so a released but still-focused range accepts preset echoes. Input events preview locally and change events commit; gesture cleanup never overwrites the pending value before change. An element blur during a WebKit drag is not a release; pointer release/cancel, capture loss and window blur end protection. Blocklist rendering is deferred while its inline editor is active, including external enable/word-list changes. Explicit file-dialog selections force a disk refresh; list selections reuse the session document, and a failed refresh preserves the active source. Reselecting the current document retains its date slice and pending/successful load state; only changed projections are resent, and a disabled unchanged renderer resumes with one playback snapshot. Font family/weight intents carry only the edited field; main merges them before forwarding, so delayed sidebar echoes cannot overwrite the other field. Documents, cached projections and native callback handles are runtime resources outside the settings snapshot.

Style preset values live only in main. Sidebar sends one named intent, and main commits all preset parameters together and sends one complete appearance tuple to overlay. The old renderer keeps its original scale, font, stroke and speed until one replacement is built. A speed update arriving during a pending style rebuild is consumed by that replacement, never applied to the old renderer. This prevents a large-font/old-slow-speed frame when moving from Balanced to Nico.

OpenCC is loaded with package-local `require` while the main entry script is executing. IINA's native resolver depends on that script stack, so asynchronous callbacks only construct/use the converter. The bundle loads once and converter construction remains lazy; no WebView path reports or eval are used.

The overlay clock stores pure video time. Offset is applied only at drawing. Enabling and loading carry `{enabled, time, paused, speed}` atomically; pause/speed changes reanchor pure video time. Seek detection compares actual movement with elapsed wall time at the current playback rate, with a smaller drift threshold for forward nudges. Completed native `mpv.seeking` events explicitly synchronize even sub-threshold seeks. Only `overlay-ready` completes initialization. A pending load slot always points to the latest selected source/settings. `isLoaded` and the success OSD wait for the current render acknowledgment; success does not resend the file list. Failure clears the active selection/overlay while retaining the file and error row for explicit retry. Navigation invalidates old acknowledgments immediately.

The forked engine owns `scrollSpeed`, including CSS transitions, Canvas displacement, derived visibility ranges and collision sampling. `setScrollSpeed()` retains parsed comment instances, native `long`/`@N`, measured glyphs and existing CSS nodes. Owner motion remains native. Multiple runtime updates coalesce into one timeline/lane recalculation at the next draw; positions reflect the new motion model. CSS nodes restart once using alternating equivalent animation names, with no per-node forced layout reads. The sidebar previews speed while dragging and commits on release; visible paused playback performs one immediate draw. This is not constant-time, and no order-of-magnitude performance claim is made. The plugin does not inject duration commands or rebuild the renderer when only speed changes. While disabled, it retains settings and current projection inputs without sending source reloads, constructing renderers or drawing into hidden DOM. Style rebuilds remain pending; enabling compares the latest projection and either loads it once or resumes/rebuilds the existing source once.

DDP writes are serialized and failures do not poison the queue. A versioned cache stores canonical comments; old cache rows are normalized on read. Independent request generations reject obsolete matching, searches and bangumi responses.

## Engine provenance and validation

The bundled `overlay/lib/niconicomments.min.js` is generated from the sibling `niconicomments-dom` repository, commit `e1632bd`, on `codex/canonical-danmaku-ir`. Use the fork's existing `rolldown -c rolldown.config.mjs` build and copy `dist/bundle.js`; do not hand-edit the vendored file.

- Plugin: `node --test test/*.test.js` and syntax checks for all entry/module files.
- Engine: TypeScript check, JavaScript/declaration builds, `vitest run`, and `playwright test -c playwright.motion.config.ts` (WebKit).
- WebKit CA tests verify that disabling duplicate removal keeps viewer/owner IDs and CA layers in CSS and Canvas. The actual plugin overlay also matches the four source/list records for Nico XML, V1 and legacy JSON. A delayed-echo font test preserves weight 800 while changing family.
- The WebKit motion test verifies DOM/instance reuse, one restart per scrolling node, zero `offsetWidth` reads during speed changes, preserved owner motion, paused state, bottom alignment, colored suffixes and the shared horizontal motion formula.
- WebKit mouse-drag checks verify local speed/weight previews, one commit per completed gesture, and preset values/labels updating even with retained range focus. Unit coverage includes release outside the control, cancellation, capture loss, window blur and input blur during an ongoing drag.
- A WebKit frame-sampling check exercises the actual sidebar intent → main transaction → overlay message, including delayed delivery. On a fixed test corpus it observes only complete Balanced and Nico states (42 → 21 DOM comments), one appearance message and one renderer replacement.
- An additional local WebKit smoke run loaded the plugin's actual overlay and sidebar HTML, exercised mixed Flash/HTML5 comments and literal template characters, and confirmed snapshot/settings traffic, font spaces/caret preservation Canvas activation from a disabled state, composing-only IME commit sequences, empty Custom mode, inline blocklist drafts and deferred hidden rendering without page errors.

The plugin still has no build step or runtime package manager. Release packaging includes `danmaku-document.js` and omits the retired `overlay/input.js`.
